# 📚 BookManager

Aplicación web CRUD para gestionar una base de datos de libros, desarrollada con **HTML**, **CSS**, **JavaScript**, **PHP** y **MySQL**.  
Este proyecto permite crear, visualizar, editar y eliminar registros de libros de forma sencilla, integrando una interfaz web amigable con conexión a base de datos.

---

## 🗂️ Estructura del repositorio

📦 BookManager  
├── src/ → Código fuente (HTML, CSS, JS, PHP)  
├── dbf/ → Archivo .sql con la estructura de la base de datos  
└── README.md → Este archivo  

---

## ⚙️ Instalación y uso

1. Instalar [XAMPP](https://www.apachefriends.org/es/index.html) o un entorno similar con Apache y MySQL.  
2. Clonar este repositorio dentro de la carpeta `htdocs` de XAMPP.  
3. Iniciar los módulos **Apache** y **MySQL** desde el panel de control de XAMPP.  
4. Importar el archivo SQL ubicado en la carpeta `dbf/` dentro de **phpMyAdmin** para crear la base de datos.  
5. Abrir el navegador y acceder a:  http://localhost/BookManager/src/index.php
